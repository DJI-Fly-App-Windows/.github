## Overview
DJI Fly for Windows brings drone piloting, a live camera view, and flight footage management together in a single app for compatible DJI drones. Pilots use it to check flight status at a glance, plan a route before takeoff, and review recorded clips once they've landed. The checklist below walks through getting set up from a fresh install to a first flight.

## Features
- [ ] Live camera view streamed directly from a connected DJI drone.
- [ ] On-screen flight controls with real-time telemetry.
- [ ] Route and waypoint planning through the built-in map.
- [ ] DJI Fly Safe notices that flag flight restrictions and safety information for your area before takeoff.
- [ ] Quick-edit tools for turning flight footage into a shareable clip.

## System Requirements
- [ ] **OS:** A recent 64-bit edition of Windows
- [ ] **Processor:** A modern multi-core processor
- [ ] **Memory:** Enough RAM for smooth live video handling
- [ ] **Storage:** Free disk space for the app and any saved flight footage

## Getting Started
- [ ] Sign in with a DJI account when prompted.
- [ ] Pair your remote controller and drone.
- [ ] Check the map view and any DJI Fly Safe notices for your location before taking off.
- [ ] Fly, then review your recorded footage from the app's library.

## FAQ
- [ ] **Is DJI Fly free?** — Yes, DJI Fly is free to download and use; a compatible DJI drone is required and sold separately.
- [ ] **What does DJI Fly Safe do?** — It displays flight restriction and safety information for your area so you can review it before takeoff; it's an informational safety feature, not a way around any restriction.
- [ ] **Which versions of Windows are supported?** — Recent 64-bit versions of Windows are supported.
- [ ] **License:** DJI Fly is free, proprietary software published by DJI; it is not open-source.
